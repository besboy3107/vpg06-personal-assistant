# VPg06 - Персональный ассистент на Haystack

## Реализованные требования

1. **Haystack-агент** на `haystack-ai` с тремя инструментами и `max_agent_steps=5`.
2. **Новый инструмент** — `get_weather(city)`: погода через `wttr.in` (бесплатный API, без ключа). Агент знает о нём через системный промпт и вызывает по запросу о погоде.
3. **Системный промпт обновлён**: описывает все три инструмента, правила их использования и инструкцию включать URL изображения в ответ.
4. **Только тексты пользователя в Pinecone** — ответы агента не сохраняются (тот же принцип, что в VPg05).
5. **Долговременная память** через `PineconeManager` (reused from VPg05): перед ответом агент получает релевантный контекст из Pinecone.
6. **Краткосрочная история** в `chat_histories` (dict по user_id), ограничена 10 парами.
7. **Фото собак** отправляются как `send_photo` с текстом-анализом как `caption`.

## Что нового по сравнению с VPg05

- Фреймворк: `haystack-ai` вместо прямого OpenAI API
- Инструменты вынесены в `tools.py` и оборачиваются в `haystack.tools.Tool`
- Haystack-агент сам решает, какой инструмент вызвать
- **Новый инструмент**: погода (`get_weather`)

## Как запустить

```powershell
# 1. Создать venv
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt

# 2. Заполнить .env (скопировать из .env.example)

# 3. Запустить бота
$env:PYTHONUTF8=1; .\.venv\Scripts\python bot.py
```

## Тестирование инструментов

| Запрос пользователю | Ожидаемое поведение |
|---|---|
| "расскажи факт о кошках" | агент вызывает `get_cat_fact`, возвращает факт |
| "покажи собаку" | агент вызывает `get_dog_image_and_analysis`, бот шлёт фото с caption |
| "какая погода в Москве" | агент вызывает `get_weather("Moscow")`, возвращает описание |
| "помнишь, я говорил о..." | агент находит контекст в Pinecone и использует его |

## Проверка памяти Pinecone

Сохраняются только сообщения пользователя:
```
[INFO] Память: action=inserted | score=— | 'покажи собаку'
[INFO] Память: action=updated  | score=0.912 | 'покажи мне собаку'   ← дубликат
[INFO] Память: action=inserted | score=— | 'какая погода в москве'
```

## Учтены замечания преподавателя (VPg05)

- Тест `pinecone_manager.py` проверяет именно пару «Хочу на Марс» / «Я полечу на Марс» из задания (а не произвольные фразы).
